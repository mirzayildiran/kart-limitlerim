# Katkı rehberi

1. `main` dalından yeni bir dal aç: `feat/…`, `fix/…`, `docs/…`.
2. Değişikliğini yap; `npm run typecheck`, `npm test` ve `npm run build` temiz geçsin.
3. Commit mesajları [Conventional Commits](https://www.conventionalcommits.org/tr/) biçiminde olsun: `feat: harcama kategorileri`.
4. Pull request aç ve ne değiştiğini, nasıl denediğini yaz.

Gerçek kişisel veri (bakiye, kart bilgisi, ekran görüntüsü) içeren dosyaları asla commit'leme. Testlerde uydurma örnek veri kullan.
